## Dev Notes

### Previous Story Insights
Stories 2.1.1 and 2.1.2 established the observability infrastructure and AI provider client. This story integrates these components by adding the personality layer and connection validation that will enable meaningful AI interactions.

### Data Models
**Prompt-related Data Models:**
```python
class PromptTemplate(BaseModel):
    """Template for system prompts with versioning."""
    template_id: str = Field(..., description="Unique template identifier")
    version: str = Field(..., description="Template version for A/B testing")
    content: str = Field(..., description="Prompt template content")
    variables: List[str] = Field(..., description="Available template variables")
    metadata: Dict[str, Any] = Field(default_factory=dict, description="Template metadata")

class HealthCheckResponse(BaseModel):
    """Response model for AI health check endpoint."""
    status: str = Field(..., description="Health status (healthy/unhealthy)")
    provider: str = Field(..., description="AI provider name")
    traced: bool = Field(..., description="Whether tracing is working")
    timestamp: datetime = Field(..., description="Check timestamp")
    error: Optional[str] = Field(None, description="Error message if unhealthy")
```

### API Specifications
- **AI Health Check Endpoint:** `GET /api/health/ai`
  - Request: None
  - Response: `{"status": "healthy", "provider": "openai", "traced": true, "timestamp": "2025-08-22T12:00:00Z"}`
  - Error Response: `{"status": "unhealthy", "error": "connection_failed", "timestamp": "2025-08-22T12:00:00Z"}`

- **System Prompt Management:** Internal API for prompt loading and validation
  - No external endpoints - internal component interface

### Component Specifications
- **System Prompts Module** (`packages/backend/agents/prompts.py`):
  - Template-based prompt generation with variable substitution
  - Support for prompt versioning and A/B testing
  - Structured prompt components for different DM scenarios
  - Integration with campaign context and character information

- **Health API Component** (`packages/backend/api/health_api.py`):
  - FastAPI router with health check endpoints
  - Integration with AI client and observability services
  - Comprehensive error handling with correlation ID tracking
  - Response formatting for monitoring systems
