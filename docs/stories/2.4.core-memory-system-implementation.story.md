# Story 2.4: Core Memory System Implementation

**Status:** Draft

---

## Story

**As a** player, **I want** the AI DM to remember what has happened in our campaign, **so that** the story is coherent and my actions have lasting impact.

## Acceptance Criteria

1. The system can create, read, update, and delete key events or facts for an active campaign (e.g., "Player met NPC Gundren," "The party cleared the goblin cave").
2. The AI's context for generating a new response includes relevant memories from the current campaign.
3. The AI can demonstrate recall by referencing a past event in its narrative when prompted or appropriate.
4. The campaign memory persists between bot restarts.

### Data Models
**Memory Data Models:**
```python
class MemoryEvent(BaseModel):
    """Represents a historical event in the campaign chronicle."""
    event_id: str = Field(..., description="Unique event identifier")
    timestamp: datetime = Field(..., description="When the event occurred")
    event_type: Literal["narrative", "combat", "social", "exploration"] = Field(..., description="Type of event")
    description: str = Field(..., description="Human-readable event description")
    participants: List[str] = Field(..., description="Characters/NPCs involved")
    location: Optional[str] = Field(None, description="Where the event occurred")
    metadata: Dict[str, Any] = Field(default_factory=dict, description="Additional event data")

class MemoryFact(BaseModel):
    """Represents a persistent fact about the campaign world."""
    fact_id: str = Field(..., description="Unique fact identifier")
    fact_type: Literal["npc", "location", "quest", "relationship", "knowledge"] = Field(..., description="Type of fact")
    subject: str = Field(..., description="Primary subject of the fact")
    description: str = Field(..., description="Fact description")
    confidence: float = Field(..., ge=0.0, le=1.0, description="AI confidence in this fact")
    last_updated: datetime = Field(..., description="When fact was last updated")
    source: str = Field(..., description="Source of this knowledge")

class MemoryContext(BaseModel):
    """Context structure for AI memory integration."""
    recent_events: List[MemoryEvent] = Field(..., description="Recent campaign events")
    relevant_facts: List[MemoryFact] = Field(..., description="Facts relevant to current context")
    character_knowledge: Dict[str, List[str]] = Field(..., description="What each character knows")
    world_state: Dict[str, Any] = Field(..., description="Current world state snapshot")
    summary: str = Field(..., description="Condensed memory summary for AI")
```

### API Specifications
- **Memory Operations (Optional Admin API):** `POST /api/campaigns/{campaign_id}/memory`
  - Create: Add new memory event or fact
  - Read: Retrieve campaign memory context
  - Update: Modify existing memory facts
  - Delete: Remove obsolete memories
- **Integration Points:** CampaignMemoryService integration with DM Graph and AI client
- **File Structure:** YAML files in `data/campaigns/{campaign_id}/` directory
- **Performance:** Memory retrieval should complete within 50ms for AI integration

### Component Specifications
- **CampaignMemoryService Component** (`packages/backend/components/campaign_memory_service.py`):
  - Four-tiered persistence implementation following architecture strategy
  - YAML file management for chronicle and living lore data
  - Memory context preparation and relevance scoring
  - Integration with LangGraph for AI memory injection
  - Error handling and recovery for memory file corruption
- **Memory Files Structure** (`data/campaigns/{campaign_id}/`):
  - `chronicle.yaml` - Append-only historical events
  - `npcs.yaml` - NPC states and relationships
  - `locations.yaml` - Location descriptions and states
  - `party_state.yaml` - Party knowledge and status
  - `player_characters.yaml` - Character-specific memories
