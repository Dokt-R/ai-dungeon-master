## Dev Notes

### Previous Story Insights
Stories 2.2.1 and 2.2.2 established the API endpoint infrastructure and LangGraph flow. This story focuses on the memory management that enables coherent conversations and comprehensive testing to ensure the entire narrative interaction system works reliably.

### Data Models
**Memory Context Models:**
```python
class MemoryContext(BaseModel):
    """Context structure for AI memory integration."""
    recent_events: List[Dict[str, Any]] = Field(..., description="Recent conversation events")
    relevant_memories: List[str] = Field(..., description="Relevant memory snippets")
    character_knowledge: Dict[str, List[str]] = Field(..., description="Character-specific knowledge")
    world_state: Dict[str, Any] = Field(..., description="Current world state snapshot")
    summary: str = Field(..., description="Condensed memory summary for AI")
    token_count: int = Field(..., description="Estimated token count for context")

class MemoryConfig(BaseModel):
    """Configuration for memory management."""
    max_context_tokens: int = Field(default=2000, description="Maximum tokens for AI context")
    memory_relevance_threshold: float = Field(default=0.7, description="Minimum relevance score")
    max_memory_items: int = Field(default=50, description="Maximum memory items to retain")
    cleanup_interval: int = Field(default=3600, description="Cleanup interval in seconds")
```

- **Memory Integration:** Internal memory service called by DM graph
- **Performance Requirements:** Memory retrieval < 50ms, context preparation < 100ms

## Testing

**Testing Standards from Architecture:**
- **Framework:** Pytest for all unit and integration tests
- **Location:** Unit tests in `tests/unit/backend/` directory, integration tests in `tests/integration/backend/`
- **Structure:** Test files mirror the packages/ directory structure
- **Mocking:** All external dependencies (AI providers, LangGraph state, memory operations) must be mocked

- **CI Integration:** All tests run automatically in GitHub Actions
