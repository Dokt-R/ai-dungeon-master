# Story 2.2: Implement Core Narrative Interaction Loop

**Status:** Ready for Review

## Story

**As a** player, **I want** to send a prompt to the bot and receive a narrative response from the AI, **so that** I can begin to interact with the game world.

## Acceptance Criteria

1. A valid request to the `/action` endpoint successfully triggers the LangGraph flow.
2. The AI provider is called with the user's prompt and the correct conversational context.
3. The AI's narrative response is successfully returned through the API.
4. The system gracefully handles and reports any errors during the process.

### Data Models
**ActionRequest Model:**
```python
class ActionRequest(BaseModel):
    """Request model for player actions sent to the AI DM."""
    prompt: str = Field(..., description="The player's action or message to the DM")
    session_id: str = Field(..., description="Unique session identifier for conversation tracking")
    campaign_context: Optional[Dict[str, Any]] = Field(None, description="Additional campaign context")
```

**ActionResponse Model:**
```python
class ActionResponse(BaseModel):
    """Response model for AI DM narrative responses."""
    narrative: str = Field(..., description="The DM's narrative response to the player")
    session_id: str = Field(..., description="Session identifier for conversation continuity")
    metadata: Optional[Dict[str, Any]] = Field(None, description="Additional response metadata")
```

**MemoryState Model:**
```python
class MemoryState(BaseModel):
    """Represents the conversational memory state for LangGraph."""
    messages: List[Dict[str, str]] = Field(default_factory=list, description="Conversation history")
    context: Dict[str, Any] = Field(default_factory=dict, description="Additional context data")
    session_id: str = Field(..., description="Unique session identifier")
```

### API Specifications
- **Action Endpoint:** `POST /api/action`
  - Request Body: `ActionRequest` model with player prompt and session ID
  - Response: `ActionResponse` model with AI narrative and metadata
  - Headers: Standard authentication and correlation ID headers
  - Error Response: `{"error": "Error message", "correlation_id": "uuid"}`
- **Integration Points:** Depends on AI client from Story 2.1 and LangSmith tracing
- **Rate Limiting:** To be implemented based on AI provider quotas
- **Authentication:** Session-based authentication with campaign context validation

### Component Specifications
- **DM Graph Component** (`packages/backend/agents/dm_graph.py`):
  - LangGraph-based state machine for managing DM interactions
  - Nodes for prompt processing, AI service integration, and memory management
  - Error handling with graceful degradation and logging
  - Memory state persistence using in-memory storage with future database integration
- **Action API Component** (`packages/backend/api/action_api.py`):
  - FastAPI router with request/response validation using Pydantic models
  - Integration with DM graph for processing player actions
  - Comprehensive error handling with correlation ID tracking
  - Response formatting for Discord bot consumption
