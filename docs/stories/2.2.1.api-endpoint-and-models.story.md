### Data Models
**ActionRequest Model:**
```python
class ActionRequest(BaseModel):
    """Request model for player actions sent to the AI DM."""
    prompt: str = Field(..., min_length=1, max_length=2000, description="The player's action or message to the DM")
    session_id: str = Field(..., pattern=r'^[a-zA-Z0-9_-]+$', description="Unique session identifier for conversation tracking")
    campaign_context: Optional[Dict[str, Any]] = Field(None, description="Additional campaign context")
    user_id: Optional[str] = Field(None, description="User identifier for personalization")
```

**ActionResponse Model:**
```python
class ActionResponse(BaseModel):
    """Response model for AI DM narrative responses."""
    narrative: str = Field(..., min_length=1, max_length=4000, description="The DM's narrative response to the player")
    session_id: str = Field(..., description="Session identifier for conversation continuity")
    metadata: Optional[Dict[str, Any]] = Field(None, description="Additional response metadata")
    processing_time: Optional[float] = Field(None, description="Response generation time in seconds")
    status: str = Field(default="success", description="Response status")
```

### API Specifications
- **Action Endpoint:** `POST /api/action`
  - Request Body: `ActionRequest` model with validation constraints
  - Response: `ActionResponse` model with narrative and metadata
  - Headers: Standard authentication, correlation ID, and content-type headers
  - Error Response: `{"error": "Error message", "correlation_id": "uuid", "details": {...}}`
- **Validation Rules:**
  - Prompt: 1-2000 characters, required
  - Session ID: Alphanumeric with dashes/underscores, required
  - Rate limiting: To be implemented based on AI provider quotas
- **Authentication:** Session-based authentication with campaign context validation

### Component Specifications
- **Action API Component** (`packages/backend/api/action_api.py`):
  - FastAPI router with request/response validation using Pydantic models
  - Input sanitization and validation middleware
  - Comprehensive error handling with correlation ID tracking
  - Response formatting optimized for Discord bot consumption
  - Integration points for future AI service connection
