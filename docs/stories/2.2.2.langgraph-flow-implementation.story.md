**MemoryState Model:**
```python
class MemoryState(BaseModel):
    """Represents the conversational memory state for LangGraph."""
    messages: List[Dict[str, str]] = Field(default_factory=list, description="Conversation history")
    context: Dict[str, Any] = Field(default_factory=dict, description="Additional context data")
    session_id: str = Field(..., description="Unique session identifier")
    turn_count: int = Field(default=0, description="Number of conversation turns")
    last_activity: datetime = Field(default_factory=datetime.utcnow, description="Last activity timestamp")
```

**Graph State Model:**
```python
class DMGraphState(TypedDict):
    """LangGraph state for DM interactions."""
    user_prompt: str
    memory_state: MemoryState
    system_prompt: str
    ai_response: Optional[str]
    narrative_response: Optional[str]
    error: Optional[str]
    correlation_id: str
```
