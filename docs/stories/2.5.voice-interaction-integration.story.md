# Story 2.5: Voice Interaction Integration

**Status:** Draft

---

## Story

**As a** player, **I want** to be able to speak to the AI DM and hear it speak back, **so that** I can have an immersive, hands-free gameplay experience.

## Acceptance Criteria

1. The bot can join a Discord voice channel.
2. The bot can listen to and accurately transcribe a player's spoken words into a text prompt.
3. The AI's text response is successfully converted to speech audio.
4. The generated audio is played back to the user in the voice channel.
5. The average roundtrip latency (from end of user speech to beginning of bot speech) for a standard interaction meets the `NFR1` target of under 4 seconds.

### Data Models
**Voice Interaction Data Models:**
```python
class VoiceSession(BaseModel):
    """Represents an active voice interaction session."""
    session_id: str = Field(..., description="Unique voice session identifier")
    channel_id: str = Field(..., description="Discord voice channel ID")
    guild_id: str = Field(..., description="Discord guild ID")
    participants: List[str] = Field(..., description="User IDs participating in voice")
    start_time: datetime = Field(..., description="Session start timestamp")
    status: Literal["active", "inactive", "error"] = Field(..., description="Session status")
    stt_provider: str = Field(..., description="Speech-to-text provider in use")
    tts_provider: str = Field(..., description="Text-to-speech provider in use")

class AudioTranscription(BaseModel):
    """Result of speech-to-text processing."""
    transcription_id: str = Field(..., description="Unique transcription identifier")
    session_id: str = Field(..., description="Voice session ID")
    user_id: str = Field(..., description="User who spoke")
    text: str = Field(..., description="Transcribed text")
    confidence: float = Field(..., ge=0.0, le=1.0, description="Transcription confidence score")
    timestamp: datetime = Field(..., description="Transcription timestamp")
    duration: float = Field(..., description="Audio duration in seconds")
    language: str = Field(..., description="Detected language code")

class VoiceResponse(BaseModel):
    """Audio response from text-to-speech processing."""
    response_id: str = Field(..., description="Unique voice response identifier")
    session_id: str = Field(..., description="Voice session ID")
    text: str = Field(..., description="Original text for speech synthesis")
    audio_url: Optional[str] = Field(None, description="Generated audio file URL")
    audio_data: Optional[bytes] = Field(None, description="Raw audio data")
    voice: str = Field(..., description="Voice ID used for synthesis")
    provider: str = Field(..., description="TTS provider used")
    duration: float = Field(..., description="Audio duration in seconds")
    format: str = Field(..., description="Audio format (wav, mp3, etc.)")
```

### API Specifications
- **Voice Session Management (Bot Commands):**
  - `/voice join` - Join the user's current voice channel
  - `/voice leave` - Leave the current voice channel
  - `/voice status` - Get current voice session status
- **Voice Interaction Endpoints (Backend API):**
  - `POST /api/voice/transcribe` - Upload audio for transcription
  - `POST /api/voice/synthesize` - Generate speech from text
  - `GET /api/voice/session/{session_id}` - Get voice session info
- **Integration Points:** NotificationService for output mode handling, AI client for text processing
- **Audio Formats:** Support for WAV, MP3, OGG for compatibility
- **Performance:** STT processing < 1 second, TTS generation < 2 seconds

### Component Specifications
- **Voice Cog Component** (`packages/bot/cogs/voice_cog.py`):
  - Discord.py voice client integration with connection management
  - Audio stream handling and real-time processing
  - Voice state monitoring and participant tracking
  - Error recovery and connection stability features
- **STT Service Component** (`packages/backend/components/stt_service.py`):
  - Provider-agnostic speech-to-text interface
  - Audio preprocessing and format conversion
  - Confidence scoring and fallback mechanisms
  - Integration with voice cog audio streams
- **TTS Service Component** (`packages/backend/components/tts_service.py`):
  - Provider pattern implementation for multiple TTS services
  - Voice selection and audio format optimization
  - Audio caching and performance optimization
  - Integration with NotificationService for voice responses
