# Story 2.4.3: AI Integration & Context Management

**Status:** Approved

---

## Story

**As a** developer, **I want** to integrate the memory system with AI interactions and implement context management, **so that** the AI can provide coherent, contextually aware responses using campaign memory.

## Acceptance Criteria

1. Memory context injection into AI prompts is properly implemented and tested.
2. Memory retrieval tools for AI to access campaign history are working correctly.
3. Memory summarization for context window optimization is functioning.
4. AI integration with LangGraph memory nodes is complete.

  - [ ] Create memory context preparation functions with relevance scoring
  - [ ] Implement context injection into AI prompts from system prompt service
  - [ ] Add context window management to stay within AI token limits
  - [ ] Create memory filtering based on relevance and recency

- [ ] **Task 2:** Add memory retrieval tools for AI integration.
  - [ ] Create LangGraph tools for memory access and search
  - [ ] Implement memory query capabilities for AI to access campaign history

  - [ ] Create memory search with semantic and keyword matching

- [ ] **Task 3:** Implement memory summarization algorithms.
  - [ ] Define memory summarization algorithms for context optimization
  - [ ] Add context window optimization strategies for AI prompts
  - [ ] Implement memory prioritization based on relevance scores
  - [ ] Create memory compression for long-running campaigns

- [ ] **Task 4:** Integrate memory system with LangGraph DM flow.
  - [ ] Update DM graph from Story 2.2.2 to include memory loading nodes
  - [ ] Add memory context injection into graph execution flow
  - [ ] Implement memory updates after AI responses and player actions
  - [ ] Create memory persistence across graph executions

  - [ ] Implement memory relevance scoring algorithms

### Data Models
**AI Integration Models:**
```python
class MemoryQuery(BaseModel):
    """Query structure for AI memory access."""
    query_type: Literal["search", "context", "summary"] = Field(..., description="Type of memory query")
    prompt_context: str = Field(..., description="Current AI prompt context")
    relevance_threshold: float = Field(default=0.7, description="Minimum relevance score")
    max_results: int = Field(default=10, description="Maximum memory items to return")
    time_window: Optional[timedelta] = Field(None, description="Time window for memory search")

class MemoryContextPackage(BaseModel):
    """Packaged memory context for AI integration."""
    relevant_events: List[MemoryEvent] = Field(..., description="Relevant historical events")
    pertinent_facts: List[MemoryFact] = Field(..., description="Important facts for context")
    character_context: Dict[str, List[str]] = Field(..., description="Character-specific context")
    world_state_summary: str = Field(..., description="Condensed world state")
    context_size: int = Field(..., description="Estimated token count")
    relevance_score: float = Field(..., description="Overall context relevance")
```

**Tool Integration Models:**
```python
class MemoryToolResult(BaseModel):
    """Result from memory tool execution."""
    tool_name: str = Field(..., description="Name of memory tool executed")
    query: str = Field(..., description="Original query that triggered tool")
    results: List[Dict[str, Any]] = Field(..., description="Memory items retrieved")
    execution_time: float = Field(..., description="Tool execution time")
    relevance_score: float = Field(..., description="Results relevance score")
    summary: str = Field(..., description="Condensed results summary for AI")
```
