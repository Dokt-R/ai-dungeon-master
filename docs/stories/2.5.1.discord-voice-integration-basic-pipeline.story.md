### Data Models
**Voice Integration Models:**
```python
class VoiceChannelInfo(BaseModel):
    """Information about a Discord voice channel."""
    channel_id: str = Field(..., description="Discord voice channel ID")
    guild_id: str = Field(..., description="Discord guild ID")
    channel_name: str = Field(..., description="Voice channel name")
    user_limit: Optional[int] = Field(None, description="User limit for channel")
    bitrate: int = Field(..., description="Channel bitrate")
    region: str = Field(..., description="Voice region")

class VoiceConnection(BaseModel):
    """Represents an active voice connection."""
    connection_id: str = Field(..., description="Unique connection identifier")
    channel_id: str = Field(..., description="Connected voice channel ID")
    status: Literal["connecting", "connected", "disconnected", "error"] = Field(..., description="Connection status")
    connected_at: datetime = Field(default_factory=datetime.utcnow, description="Connection start time")
    participants: List[str] = Field(default_factory=list, description="User IDs in voice")
    error_message: Optional[str] = Field(None, description="Last error message")

class VoicePermission(BaseModel):
    """Voice channel permissions for users and bot."""
    user_id: str = Field(..., description="User or bot ID")
    can_connect: bool = Field(..., description="Can connect to voice channel")
    can_speak: bool = Field(..., description="Can speak in voice channel")
    can_mute_members: bool = Field(..., description="Can mute other members")
    can_deafen_members: bool = Field(..., description="Can deafen other members")
    can_move_members: bool = Field(..., description="Can move members between channels")
```

- **Voice Commands:** Bot slash commands for voice management

  - `/voice status` - Get voice connection status

- **Voice Integration:** Internal voice connection management APIs
- **Performance:** Voice connection operations should complete within reasonable bounds
