# Story 2.4.2: YAML Persistence Layer

**Status:** Approved

---

## Story

**As a** developer, **I want** to implement the YAML-based persistence layer for campaign memory, **so that** memory data can be reliably stored and retrieved across system restarts.

## Acceptance Criteria

1. YAML file structure for chronicle and living lore data is properly designed and implemented.
2. Memory file reading/writing operations use atomic operations with proper error handling.
3. Data validation and schema enforcement are implemented for memory files.
4. Memory file backup and recovery mechanisms are in place.

### Data Models
**YAML Schema Models:**
```python
class ChronicleSchema(BaseModel):
    """Schema for chronicle.yaml - historical campaign events."""
    version: str = Field(..., description="Schema version")
    campaign_id: str = Field(..., description="Campaign identifier")
    events: List[Dict[str, Any]] = Field(..., description="Historical events")
    created_at: datetime = Field(..., description="File creation timestamp")
    last_modified: datetime = Field(..., description="Last modification timestamp")

class NPCSchema(BaseModel):
    """Schema for npcs.yaml - NPC states and relationships."""
    version: str = Field(..., description="Schema version")
    npcs: Dict[str, Dict[str, Any]] = Field(..., description="NPC data by ID")
    relationships: Dict[str, List[str]] = Field(..., description="NPC relationships")
    last_updated: datetime = Field(..., description="Last update timestamp")

class LocationSchema(BaseModel):
    """Schema for locations.yaml - location descriptions and states."""
    version: str = Field(..., description="Schema version")
    locations: Dict[str, Dict[str, Any]] = Field(..., description="Location data by ID")
    connections: Dict[str, List[str]] = Field(..., description="Location connections")
    last_updated: datetime = Field(..., description="Last update timestamp")

class PartyStateSchema(BaseModel):
    """Schema for party_state.yaml - party knowledge and status."""
    version: str = Field(..., description="Schema version")
    party_members: List[str] = Field(..., description="Current party members")
    knowledge: Dict[str, List[str]] = Field(..., description="Party knowledge by character")
    quests: Dict[str, Dict[str, Any]] = Field(..., description="Active quest states")
    last_updated: datetime = Field(..., description="Last update timestamp")
```

**File Operation Models:**
```python
class FileOperation(BaseModel):
    """Result of a file operation."""
    operation: Literal["read", "write", "backup", "restore"] = Field(..., description="Operation type")
    file_path: str = Field(..., description="Path to the file")
    success: bool = Field(..., description="Whether operation succeeded")
    error: Optional[str] = Field(None, description="Error message if failed")
    timestamp: datetime = Field(default_factory=datetime.utcnow, description="Operation timestamp")
    backup_path: Optional[str] = Field(None, description="Backup file path if applicable")

class FileValidation(BaseModel):
    """Result of file validation."""
    file_path: str = Field(..., description="Path to the validated file")
    is_valid: bool = Field(..., description="Whether file passed validation")
    schema_version: str = Field(..., description="Schema version found")
    errors: List[str] = Field(..., description="Validation errors found")
    warnings: List[str] = Field(..., description="Validation warnings")
```

### API Specifications
- **File Operations:** Internal component interface for YAML file management
- **Performance Requirements:** File operations < 50ms for reads, < 100ms for writes
- **Atomicity:** All write operations must be atomic to prevent corruption
- **Backup:** Automatic backup before any write operation

### Component Specifications
- **YAML Persistence Service** (`packages/backend/components/yaml_persistence_service.py`):
  - YAML file management with atomic operations
  - Schema validation and data integrity checking
  - Backup and recovery functionality
  - Performance optimization with caching
  - Error handling and corruption recovery

- **File Manager** (`packages/backend/components/file_manager.py`):
  - Low-level file operations with atomic writes
  - File locking and concurrent access management
  - Backup management and rotation
  - File system monitoring and health checks
