### Implementation Guidance

**Important Context:**
- Comprehensive unit tests already exist for the Discord error handler in `tests/unit/shared/test_unit_error_handler.py`
- The existing integration tests in `tests/integration/backend/test_error_handler.py` focus on business logic scenarios rather than direct exception handler testing
- AIAPIError tests are currently skipped in the existing integration file - check if AI API is implemented before enabling

1. For FastAPI exception handler tests (`tests/integration/backend/test_error_handler.py`):
   - Create a test client using `TestClient` from `fastapi.testclient`
   - Create test endpoints that raise specific exceptions:
     ```python
     from fastapi import FastAPI, HTTPException
     from packages.shared.error_handler import ValidationError, NotFoundError, AIAPIError
     
     app = FastAPI()
     
     @app.get("/test-validation-error")
     async def test_validation_error():
         raise ValidationError("Test validation error")
     
     @app.get("/test-not-found-error")
     async def test_not_found_error():
         raise NotFoundError("Test not found error")
     
     @app.get("/test-ai-api-error")
     async def test_ai_api_error():
         raise AIAPIError("Test AI API error")
     
     @app.get("/test-generic-error")
     async def test_generic_error():
         raise Exception("Test generic error")
     ```
   - Write tests that make requests to these endpoints and verify responses:
     ```python
     from fastapi.testclient import TestClient
     
     def test_validation_error_handler():
         response = client.get("/test-validation-error")
         assert response.status_code == 400
         assert "error" in response.json()
         assert response.json()["error"]["code"] == "VALIDATION_ERROR"
     
     # Similar tests for other exception types
     ```

2. For Discord error handler tests (`tests/unit/bot/test_error_handling_cogs.py`):
   - Mock Discord interaction objects
   - Create test cogs with commands that raise specific exceptions
   - Use `unittest.mock` to verify that the correct messages are sent:
     ```python
     import pytest
     from unittest.mock import AsyncMock, MagicMock
     from packages.shared.error_handler import ValidationError, NotFoundError, AIAPIError
     
     # Mock interaction object
     mock_interaction = AsyncMock()
     mock_interaction.response.send_message = AsyncMock()
     mock_interaction.followup.send = AsyncMock()
     
     # Test function that uses the decorator
     @discord_error_handler()
     async def test_command_that_raises_validation_error(interaction):
         raise ValidationError("Test validation error")
     
     async def test_discord_validation_error():
         await test_command_that_raises_validation_error(mock_interaction)
         mock_interaction.response.send_message.assert_called_once_with(
             "Test validation error", ephemeral=True
         )
     
     # Similar tests for other exception types
     ```

3. For AIAPIError tests:
   - Add test cases in both test files that specifically test the `AIAPIError`
   - Verify that it's handled correctly in both FastAPI and Discord contexts

### Testing Standards

- **Test file location**:
  - `tests/integration/backend/test_error_handler.py` for FastAPI tests
  - `tests/integration/bot/test_error_handling_cogs.py` for Discord tests
  
- **Test standards**: 
  - Follow the existing test patterns in the codebase
  - Use `pytest` for test framework
  - Use `unittest.mock` for mocking external dependencies
  - Ensure tests are isolated and don't depend on external services
  
- **Testing frameworks and patterns to use**:
  - `pytest` for test framework
  - `TestClient` from `fastapi.testclient` for FastAPI integration tests
  - `unittest.mock` for mocking Discord interactions
  - `pytest-cov` for coverage reporting
  
- **Specific testing requirements for this story**:
  - Test all exception types in FastAPI context
  - Test all exception types in Discord context
  - Verify correct HTTP status codes for API responses
  - Verify correct messages are sent to Discord users
  - Verify that generic exceptions result in sanitized messages
  - Verify that custom exceptions provide appropriate messages
  - Test the new `AIAPIError` in both contexts
